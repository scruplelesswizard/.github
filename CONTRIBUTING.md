# Contributing

Thanks for taking the time to contribute.

## Before you start

- For bugs, open an issue with steps to reproduce.
- For larger changes or new features, open an issue first so we can agree on the approach before you
  spend time on it.
- Small fixes (typos, docs, obvious bugs) can go straight to a pull request.

## Pull requests

1. Fork the repository and create a branch from the default branch.
2. Keep the change focused: one fix or feature per pull request.
3. Add or update tests and documentation where it makes sense.
4. Make sure CI passes.
5. Write a clear title. Pull requests are squash-merged and the title becomes the commit message.

## Code of conduct

Be kind and assume good faith. Harassment or abuse will not be tolerated and may result in a block.
